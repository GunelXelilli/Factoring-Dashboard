# Factoring Dashboard

Interactive Power BI report for monitoring a factoring portfolio: contracts, open receivables, overdue invoices, debtor ageing and payments.

Built on synthetic mock data (12 clients, 22 contracts, ~770 invoices, ~560 payments). Report labels are in Serbian.

Pages
Open Receivables – open, overdue and not-yet-due amounts by client
Debtors / Ageing – number of debtors, largest debtor, ageing buckets (0–30, 31–60, 61–90, 90+ days)
Delays – overdue amounts by client and contract
Payments – total paid, on-time payment %, payments by month and status
Contracts – number of contracts and clients, total limit, contract list
